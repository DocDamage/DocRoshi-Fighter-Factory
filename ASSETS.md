# Playable Asset Bundle

The public `DocRoshi-Fighter-Factory` repository contains source, tools, launchers,
reports, and evidence. It does not store the playable third-party IKEMEN/MUGEN
runtime assets directly.

Playable assets are stored separately in the private GitHub repository:

https://github.com/DocDamage/DocRoshi-Fighter-Factory-Assets

Current private release:

https://github.com/DocDamage/DocRoshi-Fighter-Factory-Assets/releases/tag/playable-assets-20260614-mbevo-swr

Bundle files:

- `DocRoshi-IKEMEN-MBEVO-SWR-20260614.7z.001`
- `DocRoshi-IKEMEN-MBEVO-SWR-20260614.7z.002`

Download both parts into the same folder, then extract the `.001` file with
7-Zip. The extracted build is the IKEMEN GO MBEVO branch with the MBEVO
character select screen, Scarlet Weather Rhapsody arranged lifebars, and the
current roster/stages/assets captured from the local runtime.

Keep this bundle private unless the redistribution status of every included
third-party character, stage, screenpack, lifebar, sound, and archive is verified.
